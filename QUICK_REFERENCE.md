## 🎮 Games Quick Guide

### 🐍🪜 Snake & Ladder
**How to Play:** Click "Roll Dice" → Move automatically → Avoid snakes, climb ladders → Reach 100 to win!
**Skills:** Numbers 1-100, counting, strategy

### 🎲 Ludo
**How to Play:** Roll dice → Move tokens → Roll 6 for extra turn → First to finish wins!
**Skills:** Counting, turn-taking, colors

### 🧠 Memory Match
**How to Play:** Click cards to flip → Find matching pairs → Complete all pairs to win!
**Skills:** Memory, concentration, matching

### 🔤 Word Builder
**How to Play:** See hint emoji → Click letters to build word → Use undo if needed → Complete all words!
**Skills:** Spelling, vocabulary, letter recognition

### ⚡ Math Race
**How to Play:** Click "Start Race" → Solve problems fast → Build streaks → Beat the 60-second timer!
**Skills:** Mental math, speed calculation, arithmetic

### 🎨 Pattern Game
**How to Play:** See color pattern → Choose missing color → Complete all 10 levels!
**Skills:** Logic, pattern recognition, sequences

### 🐝 Spelling Bee
**How to Play:** Listen to word (🔊) → See hint → Type spelling → Get hints if needed!
**Skills:** Spelling, word recognition, listening

- Clear browser cache

- Clear browser cache
- Try different browser
- Refresh the page

- Close other browser tabs
- Use Chrome/Edge for best performance

- Update browser
